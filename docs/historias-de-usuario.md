# Historias de usuario

## v0.1: catálogo y registro personal

- H1. Como visitante quiero registrarme e iniciar sesión para tener mi cuenta.
- H2. Como usuario quiero buscar juegos por título, consola, género y año para encontrar lo que me interesa.
- H3. Como usuario quiero ver la ficha de un juego (consola, año, género, carátula) para decidir si me interesa.
- H4. Como usuario quiero marcar un juego como Jugando, Próximo, Terminado o Abandonado para llevar mi registro.
- H5. Como usuario quiero calificar un juego y escribir una nota privada para recordar qué me pareció.
- H6. Como usuario quiero ver mi historial en orden cronológico para mirar atrás lo que he jugado.
- H7. Como usuario quiero asignar prioridad a los juegos de mi lista de pendientes para decidir qué sigue.
- H8. Como usuario quiero registrar mis dispositivos y anotar en cuál y con qué emulador jugué cada juego, y cómo corrió.
- H9. Como usuario quiero ver estadísticas de mi actividad (por consola, por año) para tener los pies en la tierra.
- H10. Como usuario quiero que me sugieran un juego de mi lista para dejar de dudar qué jugar.

## v0.2: comunidad

- H11. Como usuario quiero un perfil público (con opción de privado) para mostrar lo que he jugado.
- H12. Como usuario quiero publicar reseñas de juegos para compartir mi opinión.
- H13. Como usuario quiero crear listas temáticas para ayudar a otros.
- H14. Como usuario quiero seguir a otros y ver su actividad para descubrir juegos por gente que me gusta.

## v0.3: descubrimiento para quien empieza

- H15. Como novato quiero explorar listas populares y curadas para encontrar buenos juegos sin perderme.
- H16. Como usuario con un dispositivo quiero ver qué juegos corren bien en él, según otros usuarios.

## v0.4: RetroAchievements

- H17. Como usuario quiero vincular mi cuenta de RetroAchievements para importar mis juegos y logros.
- H18. Como usuario quiero ver mi progreso de logros por juego para saber cuánto me falta.
